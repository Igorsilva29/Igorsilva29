Desenvolvimento independente de uma aplicação web corporativa, desde a estruturação do frontend e backend até a implantação e manutenção em produção.

- Desenvolvimento de interfaces com Next.js, React e TypeScript.
- Backend desenvolvido com PHP e Laravel.
- Integração com MySQL e APIs REST.
- Implementação de autenticação, gerenciamento de dados e regras de negócio.
